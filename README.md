# Christophe LLC Website

Professional responsive hardware and tools website for **Christophe LLC**.

## Included
- Hardware and tools homepage
- Power tools, hand tools, supplies, and safety categories
- Featured product catalog
- Sample prices
- Product filtering
- Interactive cart counter
- Contractor / trade section
- About section
- Project support contact form
- Responsive mobile navigation
- GitHub Pages ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish with GitHub Pages

Upload all files to the root of the `christophellc` repository.

Then go to:

**Settings → Pages → Deploy from a branch → main / root → Save**

Product names and prices are sample content and can be replaced with your real inventory.
Photography is loaded remotely from Unsplash.
